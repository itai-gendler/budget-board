# Run automatic rule one off

## Trigger

The User submits condition and action lists for a one-off run.

## Outcome

The Product evaluates Automatic rule AND conditions and applies ordered Rule action operations to eligible Transaction records. Balance ledger effects and Tag creation/removal follow each action. The reported update count can count one record repeatedly.
